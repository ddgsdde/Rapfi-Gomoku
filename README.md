# Rapfi Gomoku

浏览器五子棋，采用 15 路棋盘，黑棋先手，默认使用自由规则，连续五子或更多即获胜。支持 Rapfi 人机对弈、同屏双人、落子提示、悔棋、逐手复盘和 JSON 棋谱导入导出。当前棋局保存在浏览器中。

「对局设置」里的「黑棋禁手」可在开局前启用。黑棋禁手由 Rapfi 判定，以 × 标出且不可落子。黑棋恰好五连获胜，白棋五连或长连获胜。黑棋无合法落点时判白棋胜。双方自由开局，切换规则会开始新对局。

轮到 AI 且有一手能成五时，棋盘会标出成五点并等待选择。「主动让一手」让 Rapfi 排除所有立即成五的落点，另选一处后交还行棋权。「按胜着落子」按正常规则结束这局棋。

AI 获胜后，仍可通过「让 AI 换一手」替换胜着，或用「悔棋重下」退回玩家上一手之前。黑白胜率随对局和复盘更新，进行中的局面显示 Rapfi 的估计值，一手成五和已结束的局面单独标明。

## 本地运行

在项目根目录启动静态服务器。

```sh
python3 -m http.server 8175 --bind 127.0.0.1 --directory dist
```

浏览器访问 [http://127.0.0.1:8175/](http://127.0.0.1:8175/)。引擎与 NNUE 权重已包含在 `dist/engine/` 中，使用支持 WebAssembly SIMD 的现代浏览器即可。

## 引擎构建

在启用 Emscripten SDK 4.0.23 且安装了 CMake、Ninja、Git 和 Python 3 的环境下，运行 `./dist/engine/build-rapfi.sh` 重建引擎。引擎源码、权重源码与许可证链接均放在 [引擎说明](dist/engine/source.html) 中。
